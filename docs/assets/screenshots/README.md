## 截图小建议

- 只截页面本体，别带整个桌面和书签栏；浏览器窗口截图即可，别用手机拍屏。
- 涉及个人信息的（昵称、课程名、学号）先打码或换成测试号。
- PNG 优先；单张控制在 300KB 以内，太大会拖慢移动端加载。
- 宽高比尽量统一（推荐 16:10），教程页里观感会整齐很多。
