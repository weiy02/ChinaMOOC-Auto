四个场景，一个面板解决

脚本不猜、不乱点：读不到答案就不提交，识别不到列表就明确提示。所有操作都有停止按钮。

互

互评自动化

一键 / 快速 / 全自动三种节奏，解析真实分值选最高分，默认评语「科技改变生活」，带评分修复。在测验、作业、考试页会被主动拒绝执行，避免把选项当分数点掉。

讨

课堂讨论自动回复

正文取自已有楼层，不自己编内容。可按「最新答复」或「点赞最多」取值，发送前先预览：选的是哪一层、作者是谁、要发什么，一目了然。同一条讨论只回复一次。

测

随堂测验一键作答

从课件接口（MOOC）或 dwr 响应（SPOC）取正确答案，逐题比对填涂后提交。选项按「平台 ID → 文案 → 字母顺序」三级定位，SPOC 两份答案源择优采用。题目对不上时只填不交，留状态说明让你手动补完，绝不交白卷。

学

整章自动学习

视频播完 → 文档翻页 → 讨论回复 → 随堂测验作答，跨小节、跨章节自动推进。刷新后自动续跑，视频弹题默认被拦截。内容没渲染出来会自动重载，不把「白页」当已完成跳过。

自动识别 MOOC / SPOC

先看路径（/spoc/ 或 /mooc/），路径判断不了才看 DOM，且只认 SPOC 独有的下拉结构——宁可漏判 SPOC，也不把 MOOC 带进 SPOC 分支。

两套前端的内容项、题块、题库来源、讨论编辑器各不相同，脚本各走各的分支。

改版了也有办法

内置「页面 DOM 诊断」，可一键导出页面结构；日志页签记录检测结果、跳转决策与异常，带行号、可复制。「问题反馈」按钮直接跳 GitHub 新建 Issue。

平台改版后按日志里的 [type] / [load] / [nav] 三类行排查，适配速度会快很多。

面板是一张操作台，不是说明书

暗色扁平：纯色底、细边框、一个强调色，只留按钮。解释文字全收进标题栏的「?」浮层。

常见问题

视频里的弹题被拦了，进度还算数吗？

默认策略是「直接拦截」：劫持 pause 让打点那一下不真的暂停，同时扫描并收掉浮层。风险要说清楚——这是纯前端拦截，如果平台按「弹题通过数」结算学习时长，视频播完可能不计进度。

验证方法很简单：跑一个带弹题的视频，播完后刷新页面看进度涨没涨。没涨就到「设置」里关掉视频弹题拦截，脚本会退回自动作答并提交。

随堂测验和单元测验有什么区别？脚本碰哪个？

随堂测验在小节内部，与视频 / 文档平级，通常不限次数、可反复重做——脚本会作答并提交。单元测验是左侧目录里单独一个节点，往往只有一次机会——脚本不处理，考试页也会直接拒绝。

自动学习跑到测验那节，好像被跳过了？

1.14.5 起已针对这种情况修过：以前标签明明写着「测验」、页面里却没题块，脚本干等 23 秒后当成单元测验跳过。现在会先自救——结果态就点「重做」回去作答，有「开始答题」入口就点进去，都没有就重按当前标签、再不行切到相邻内容再切回来，逼平台重新请求。

仍然被跳过时，状态栏与日志会给出现场摘要（标签类型 / 可见单选框数 / 入口按钮 / 是否结果态）。把 [quiz] 那几行导出来提 Issue，能直接定位是哪一类。

SPOC 提示「没拿到 dwr 试题数据」怎么办？

SPOC 的题目答案在 dwr 响应里，脚本注入时首屏那条请求已经发完了，所以会挂 hook 等下一次。提示出现时，手动切到别的「测试」标签再切回来，触发一次新请求就行。

SPOC 的选择题总是「匹配不上」，选项一个都没勾？

1.14.4 修过一批：dwr 里的 answer 有时是 "true" 字符串或 1，字段名也可能叫 optionList / isAnswer；选项文案还常有「A、」这种前缀差异。现在会做布尔兼容、剥前缀比对，答案只给字母时按选项顺序定位。

如果还复现，「页面 DOM 诊断」里新增了【随堂测验题块实测】——每题题干、选项文案、dwr 题量与解析出的答案都在里面，附一段原始 HTML。把这段发出来就能精准适配。

评论和讨论的正文是哪来的？会不会乱编？

不会。脚本只从已经有人回复过的楼层里挑一条现成答复，并剥掉昵称、时间、点赞数这些元信息；选不出正文就直接报错退出，不拿凑数文本去发。超长正文会截到句子边界，默认上限 200 字。

页面改版、脚本失灵了怎么办？

先开「页面 DOM 诊断」导出结构，再看日志页签的判定依据，然后到 GitHub 提 Issue 并附上这两样。脚本跟着新版 UI 持续维护，反馈越具体修得越快。

近期更新

  • 1.14.5

    测验页不再被当成单元测验跳过

    标签写着「测验」、页面却还没渲染出题块时，旧逻辑只会干等 23 秒然后跳过。现在会自救：结果态点「重做」回作答态、有「开始答题」入口就点进去、重按当前标签、切到相邻内容再切回。课件确实坏了则立即放弃，不空等。题块检测也不再只认类名；视频 / 文档白页会先催一次重载。

  • 1.14.4

    SPOC 选择题匹配加固

    dwr 解析不再写死 answer === true，兼容字符串与数字真值、多种字段名；选项定位兼容 opacity:0 的假单选框，比对前剥掉「A、」这类前缀；题块按 name 分组切分；SPOC 两份答案源按「与页面题块对得上几题」择优。DOM 诊断新增【随堂测验题块实测】。

  • 1.14.3

    视频弹题改为默认拦截

    劫持 pause 让打点那一下不真的暂停，同时扫描并收掉浮层，视频不再被打断。压住暂停时留 1.2 秒观察窗，没冒浮层就补一次真暂停，不误伤手点暂停。兜底路径改为按题干匹配答案，取不到才顺位猜；同一浮层连答 5 次不消失则跳过当前视频。设置页新增「视频弹题拦截」开关。

  • 1.14.2

    设置页新增「问题反馈」

    一键打开 GitHub 新建 Issue，新标签页跳转，不受任务运行状态锁定影响。

  • 1.14.1

    类型判定改为看内容标签图标

    修复切换标签后残留的文档查看器让测验被误判成文档、进而被跳过的问题。
