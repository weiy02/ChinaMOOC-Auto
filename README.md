# 中国大学 MOOC 自动化脚本

![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)
![Platform](https://img.shields.io/badge/Platform-Tampermonkey-blue)

这是一个用于中国大学 MOOC 平台的 Tampermonkey 用户脚本，主要用于自动化完成学生互评作业流程。

---

## 功能说明

- 自动识别可评阅作业并执行评分
- 默认评语为：`科技改变生活`
- 支持批量处理与延时控制
- 提供停止按钮与评分修复能力
- **互评功能自动避开答题页**：在测验 / 作业 / 考试页面上，互评按钮会被拒绝执行（避免把题目选项当作分数选中并提交）
- **解除复制限制**：一键恢复选中、右键菜单和 Ctrl/⌘+C，开关状态会被记住

### 面板结构

面板按功能分成三个选项卡，同一时刻只显示一个视图：

| 选项卡 | 内容 |
|---|---|
| **互评** | 一键互评 / 快速互评 / 全自动互评 / 评分修复 |
| **答题** | 导入题库 / 只读演练 / 作答当前页 / 自动提交开关 / 答题探针 / 题库自检 |
| **通用** | 解除复制限制 |

打开时默认停在哪个选项卡取决于页面：**答题页（测验/作业/考试/已交卷解析）开「答题」，其余开「互评」**。只在面板创建时判定一次，之后手动切到哪就留在哪——不跟着单页路由乱跳，免得打断正在进行的操作。

三处是刻意的设计：

- **状态栏和停止按钮在选项卡之外**，常驻面板底部。任务进度和停止入口不属于任何一个视图，切走就看不到会很糟。
- **任务运行期间可以自由切选项卡**，开关类按钮（自动提交 / 解除复制）也仍可点击——它们和任务状态无关，不该被一起锁住。
- 自动提交开启时，「答题」选项卡上会挂一个**橙点**。这是整个脚本里最危险的状态，切到别的视图也必须留在视野里。

### 自动答题

核心前提：**纯代码不可能保证选出正确答案**。所以脚本不"猜"，而是构建一条分层的解析链路，并且**每一层都能明确承认"这题我不会"**——不确定的题会被红框标出来交给你，而不是随便选一个。

链路：**题库精确匹配 → 指纹匹配（题干+选项集合，选项顺序无关）→ 模糊匹配 → 未解决（红框标出）**。LLM 兜底尚未接入。

**安全设计**（都是为了让"答错"这件事尽可能不发生）：

- 题库存的是**选项文本，不是索引**
- 匹配上之后要把答案文本映射到页面上的选项元素；**映射不上就整题放弃**，绝不回退成"按索引选第 N 个"
- 多选题**只映射到一半也放弃**，并且会先摘掉页面里遗留的勾——checkbox 不像 radio 那样天然互斥
- 题库里同一道题有冲突答案时判为**歧义**，不静默取第一条
- 页面重渲染后点击前会**重新按文本定位**，避免点到失效节点上

**自动提交**默认关闭，且即使打开也还有两道闸门：**未解决题目数不为 0 就不提交**、**考试页硬阻断**（只能提交一次，失误无法挽回）。关闭自动提交时，作答完会红框标出未解决的题，由你检查后手动提交。

**推荐流程**：先点「只读演练」——它一次点击都不发，只打印"会选哪个 / 为什么放弃"，确认无误后再点「作答当前页」。

题库格式：

```json
{
  "schemaVersion": 1,
  "questions": [
    { "q": "题干原文", "t": "single", "o": ["选项甲","选项乙"], "a": ["选项乙"], "s": "verified" },
    { "q": "判断句", "t": "judge", "o": ["正确","错误"], "a": ["错误"], "s": "verified" }
  ]
}
```

`t` 为 `single` / `multi` / `judge` / `fill`；`a` 是**答案文本**（多选为多项）；`s` 是来源可信度，`scraped` > `verified` > `manual` > `llm`，冲突时取高者。

### 解除复制限制

面板「通用」选项卡下的开关。慕课挡复制通常是三套手段，脚本对应三种反制：

| 站点手段 | 反制方式 |
|---|---|
| CSS `user-select: none`（含 JS 写行内样式） | 注入带 `!important` 的样式表——样式表里的 `!important` 优先于行内样式 |
| 在 `document` / 元素上挂 `copy`、`cut`、`selectstart`、`contextmenu`、`dragstart` 处理器或 `on*` 属性 | 在 **window 捕获阶段**掐断事件传播。捕获阶段 window 早于 document，站点挂在 document 上的捕获监听也拦不住 |
| 拦截 Ctrl/⌘ + C / X / A 并 `preventDefault` | 同样在 window 捕获阶段掐断（只收窄到这三个组合键，不影响站点自身的快捷键） |

关键点是**只掐事件传播、不调用 `preventDefault`**：浏览器的选中、复制、右键菜单等默认行为得以保留，而站点挂的拦截逻辑收不到事件。

开关默认关闭，状态存在本地，刷新后保持。

### 答题探针（诊断工具）

「答题」选项卡下的「答题探针」用于在真实答题页采集页面结构，为后续的自动答题功能提供选择器依据。它**只读 DOM、不点击任何按钮、不修改任何输入**，但会包裹页面的 `XMLHttpRequest` / `fetch` 以记录请求形状。

用法：

1. 进入一个测验页，点一次「答题探针」安装网络探针并采集当前结构。
2. 在页面上手动翻一页、点一个选项或交卷。
3. 再点一次「答题探针」，取回包含网络记录在内的完整报告，点「复制」后回传。

## 使用方法

1. 安装浏览器扩展 **Tampermonkey**。
2. 打开 `main.js`，复制全部脚本内容。
3. 在 Tampermonkey 中新建脚本并粘贴保存。
4. 进入中国大学 MOOC 互评页面后按需使用脚本功能。

## 注意事项

- 请仅在你确认允许自动化处理的课程场景中使用。
- 建议先小范围测试，确认课程页面结构正常再批量执行。
