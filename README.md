# 中国大学 MOOC 学生互评自动化脚本

![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)
![Platform](https://img.shields.io/badge/Platform-Tampermonkey-blue)

这是一个用于中国大学 MOOC 平台的 Tampermonkey 用户脚本，主要用于自动化完成学生互评作业流程。

---

## 功能说明

- 自动识别可评阅作业并执行评分
- 默认评语为：`科技改变生活`
- 支持批量处理与延时控制
- 提供停止按钮与评分修复能力

## 使用方法

1. 安装浏览器扩展 **Tampermonkey**。
2. 打开 `main.js`，复制全部脚本内容。
3. 在 Tampermonkey 中新建脚本并粘贴保存。
4. 进入中国大学 MOOC 互评页面后按需使用脚本功能。

## 注意事项

- 请仅在你确认允许自动化处理的课程场景中使用。
- 建议先小范围测试，确认课程页面结构正常再批量执行。
